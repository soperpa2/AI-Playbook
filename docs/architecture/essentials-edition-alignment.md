# Essentials Edition alignment standard

The canonical site defines the framework, terminology, graphics, and shared page patterns. The Essentials Edition changes the depth and availability of content; it does not create a second framework.

## Required alignment

| Area | Shared across editions | Essentials-specific behavior |
|---|---|---|
| Brand and graphics | Logo, journey graphic, maturity graphic, colors, typography | Essentials Edition label |
| Navigation | Same public link names and order | My Account and Organization Hub are omitted |
| Plays | Same 13 play numbers, phases, canonical names, purpose, and sequence | Concise public guidance |
| Tools | Tool relationship remains attached to its play | One available Essentials Tool per play; protected tools are described but not exposed |
| Maturity model | Same five stages, five capability dimensions, explanatory copy, graphic, and card template | Links resolve to Essentials plays, learning, assessment, and tools |
| Learning | Same subject framework and public-health framing | Public module overviews and explicitly unreleased expanded materials |
| Case studies and resources | Same evidence and local-adaptation principles | Public summaries and resources only |
| Community and contribution | Same feedback and review pathways | No Organization Hub; public reviewer application remains available |
| Consulting | Same public service categories | Essentials-local consulting page and contact route |

## Link boundary

Essentials navigation, graphics, cards, and calls to action must remain inside the Essentials Edition unless a link is intentionally identified as an external source. Canonical hash routes (`#/...`) must not appear in Essentials page links.

## Current review result

- Shared navigation and page primitives are in place.
- All 13 Essentials play names match the canonical framework.
- All 13 plays have one available Essentials Tool.
- The journey graphic is shared and uses edition-local phase links.
- The maturity model is a shared asset and template with edition-local destinations.
- Edition comparison, expanded-edition information, reviewer participation, feedback, resources, and consulting pathways are present.
- My Account and Organization Hub remain intentionally excluded from Essentials.

## Change rule

Changes to shared terminology, graphics, stage definitions, navigation labels, or templates must be made in the shared `assets/` or `content/` source first. Edition-specific files should contain only access rules, local destinations, and intentionally reduced content depth.
